# Kaptan storefront and admin usability review

19 October 2026. Scope: catalogue discovery, product purchase flow, homepage media, admin navigation and product editing. Existing black/gold styling retained. Screenshots are evidence from the working UI; no customer records were changed during verification.

1. **Shop filters** — [before](01-shop-before.png). Internal categories obscured the two main product families. Added visible Kaptan Leather and Kaptan Salt Lamps collection choices, an All Products reset, compact colour chips and existing price/stock filters. Legacy category links continue to work. Verified the leather and salt collections each return three products.
2. **Product details** — [existing detail page](02-product-before.png). Gallery, variant selection and persistent purchase actions were already present. Reduced the need to open this screen by adding a variant selector and direct cart/checkout actions to listing cards. Verified adding Brown / Medium belt from its listing without opening the product page. No order was placed.
3. **Homepage** — [before](03-home-before.png), [after](home-after.png). Replaced the single hero image with all 20 public catalogue photos. Hero and listing carousels advance every four seconds, support manual controls and swipe, and pause on interaction. Reduced-motion preferences disable autoplay. Products with one image remain static.
4. **Admin product list** — [before](04-admin-products-before.png). Existing direct edit and search retained. Shared admin navigation is more compact; mobile uses a workspace selector.
5. **Admin product editor** — [before](05-admin-editor-before.png). Long scrolling and repeated image moves increased effort. Added section shortcuts, a persistent save bar, multi-image drop upload, photo drag sorting, Make cover, and Ctrl/Cmd+Enter submit with validation. Existing inventory and permission safeguards remain.
6. **Mobile storefront** — [after](mobile-after.png). Tested at 390px: no horizontal overflow; collection choices remain visible while secondary filters are collapsible.

Validation: 85 automated tests passed, TypeScript passed, production build passed. Regression coverage includes legacy category classification, invalid collection links and media reordering without mutating the original draft. Visual and interaction checks covered shopping, quick cart addition and homepage rotation. Other admin routes received source/navigation review; this is not a claim that every operational workflow was executed. No production upload, inventory adjustment, invoice, payment or order was created for testing.
